## 4. 特に修正したい問題

### 最優先: 自然文とタグの矛盾

- ID 25: 胸元を隠す指定なのに `cleavage` が付いている。
- ID 27: 二人の人物を描いているのに `solo, 1girl` が付いている。
- PixAIに渡す情報が衝突するため、生成結果に悪影響を与えるおそれがある。

### 次点: 指定されていない特徴の創作

- ID 26 の長いストレートヘア、ID 20 のレース/アンティーク調の部屋、ID 22 の衣装・ポーズ・背景など。
- 背景や照明の補完は許容できても、キャラクターの身体的特徴・人数・服色は慎重に扱いたい。

### 改善候補: 定型表現の繰り返し

- `porcelain-like skin`、`soft lighting`、`high-quality anime rendering` などが目立つ。
- 英文としては成立するが、場面ごとの表現の差が小さい。

## 5. 最終判定

- 語数: 8/8件が180〜260語。

- ローカルv9は、自然文を組み立てる部分よりも、入力条件を守りながら詳細化する部分に改善の余地が大きい。

## 6. 入力との照合メモ

評価コメントのうち、入力に既に含まれている要素を整理する。次回の修正で「指定済みの要素」を消さないため。

- **ID 21**: 入力に「黒い目」「笑顔と普通の表情の真ん中」「左側から見た構図」がある。黒い目・笑顔・横からの構図は完全な追加ではない。問題は `gentle, normal expression mixed with a bright smile` という不自然な表現と、`gentle` の追加。
- **ID 25**: 入力に「勝利の女神:ニケのシンデレラ」があるため、「女神」は設定追加ではない。`cleavage` と「胸元を隠す」の矛盾は明確な問題。
- **ID 27**: 入力は右半分と左半分にそれぞれ女の子を描く。同一人物か別人物かは明示されていない。`solo, 1girl` は二人描写と矛盾するため、どちらの解釈でもタグは要修正。
- **ID 29**: 入力に「ニケのシンデレラ」があるため、`Cinderella-like` は新設定ではなく言い換え。ただし不要な言い換えであり、`multiple_girls` は単数入力と矛盾する。

## 7. 次のアクション

1. **タグ整合性の自動チェック**を先に実装する。自然文より判定が明確で、テストしやすい。
   - 胸元を隠す/露出が少ない入力で `cleavage` / `breasts` を除去。
   - 二人以上の明示がある入力で `solo` / `1girl` を除去し、`2girls` / `multiple_girls` を補う。
   - 単数の明示がある入力で `2girls` / `multiple_girls` を除去。
   - `半分` 由来の `half_updo`、`上目遣い` 由来の `aiming` などの誤 alias を修正。
2. **v10プロンプト**で忠実さを強化する。
   - 入力から「人数・髪色/長さ/型・目色・服の種類/色・ポーズ・背景・小物」を内部チェックリスト化。
   - リストにない身体的特徴・服色・具体的な家具/小道具を追加しない。
   - 制服/メイド服に色を付けない。`white apron` / `black apron` / `white blouse` / `dark trousers` を禁止例にする。
   - 胸元を隠す指定で `cleavage` や露出表現を書かない。
   - `porcelain-like skin` などの定型句を避ける。
3. 修正後に同じ8ケース（可能なら10ケース）を再評価し、忠実さ3.5以上を目指す。
4. 機内モードはユーザー環境では実施しない。評価対象から外す。
