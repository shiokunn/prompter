# M7 クラウド生成検証（有効キー・上限なし）

日付: 2026-10-27  
APK: `0.7.3-m7` / versionCode 18（有効キー・上限なしは 0.7.2 で2ケース成功、0.7.3 の忠実さは未検証）  
CI: `40324242059`（0.7.3 のビルド）

> クラウドは **ローカルLLMが使えないときの代替**。品質の作り込みは最小限にし、接続・生成・語数上限なしが確認できれば十分とする。忠実さの再検証は低優先。

## 1. 接続確認

保存済みの OpenRouter キーで設定画面の「接続テスト」を実行した。

- 結果: `接続OK（無料枠） / 使用量 $0.00 / 上限 $0.00`
- キーは Android Keystore で暗号化保存されたまま。レポート・ログ・DBには平文を出していない。
- 以降の生成は `openrouter/free` で実行した。

## 2. 上限撤廃

クラウド生成の上限を外すため、以下を変更した。

- OpenRouter リクエストから `max_tokens` を削除。
- クラウド用プロンプトから「80〜150語」の語数上限を削除。
- クラウドは語数警告なし（`minWords = 0`, `maxWords = null`）。
- ローカルLLMは従来どおり180〜260語、オフラインは80〜150語を目安にする。
- クラウド用プロンプトは「入力への忠実さ」を優先し、語数を埋めるためのオブジェクト・色の捏造を禁止。
- `AiCache.CACHE_VERSION` を更新し、旧プロンプトのキャッシュを無効化。
- 単体テストで `max_tokens` が送信されないこと、上限なしの長文が検証を通ることを確認。

## 3. 生成結果

### ケースA: 白髪・赤目・メイド・オムライス（3分割）

入力:

> 白い髪の毛で赤い目をしたニケのシンデレラが、メイド服を着てオムライスを作っている。
> 背景は真ん中を中心とした3分割。それぞれの画面で、シンデレラが、一生懸命料理を作っているシーンを一場面ごとに違う料理工程で見せる

結果（`openrouter/free`、0.7.2 時点の詳細プロンプト）:

- **224語 / 44.3秒**
- 白髪、赤目、メイド服、オムライス、3分割を保持。
- 服装の色を捏造していない（`her apron` など色名なし）。
- 料理工程（卵を割る、混ぜる、盛り付ける）を3パネルに割り当て。
- 課題: タグに `2girls` と `multiple_girls` が入った。入力は単数で、オフライン変換側が付けたタグをクラウドが引き継いだ。入力優先のルールを追加し、再検証が必要。

### ケースB: 黒髪・青いドレス・椅子（単純な入力、0.7.2 の旧プロンプト）

- **183語 / 191.2秒**
- 入力の黒髪、青いドレス、椅子、座る姿勢は保持。
- 課題: 入力にない「白い部屋」「本」「ランプ」「ラグ」「テーブル」を追加した。語数を増やすための捏造と判断し、0.7.3 で「入力にない家具・小道具・設定要素を追加しない」ルールを追加した。

### ケースC: 黒髪・青いドレス・椅子（忠実さ重視プロンプト、0.7.3）

- `openrouter/free` で実行 -> `レート制限に達しました。少し待って再試行してください。 Provider returned error`
- 特定の無料モデル `google/gemma-4-31b-it:free` に切り替えて再実行 -> 同じレート制限エラー
- 0.7.3 の忠実さ改善は**未検証**。レート制限が解消した後に再実行する。
- エラー時もアプリは操作可能な状態に戻り、生成中のハングにはならないことを確認。

## 4. 性能とレート制限

- `openrouter/free` の生成時間は 44.3秒、191.2秒と不安定。
- 3回目の連続実行で `レート制限に達しました。少し待って再試行してください。 Provider returned error` が表示された。
- アプリはエラーを表示して操作可能な状態に戻る。生成中のハングではない。
- 無料ルーターは上流プロバイダの混雑・レート制限の影響を受ける。安定確認には時間を置いた再試行、または特定の無料モデルの指定が必要。

## 5. 判定

- 有効キーでのクラウド生成: **成功**（2ケース）。
- クラウドの語数上限撤廃: **確認済み**（224語、183語。150語上限なし）。
- 入力への忠実さ: 0.7.3 のプロンプトは**未検証**（無料枠のレート制限）。
- タグの入力優先: 0.7.3 のルールは**未検証**（同上）。
- レート制限時もアプリはエラー表示で復帰することを確認。
- 次の再検証: レート制限の解除後、ケースB/C（単純な入力）とケースA（白髪メイド、`2girls` タグ）を 0.7.3 で実行する。
